# Project Definition

#HTML
1) Form:
Used to organize code and send different data together.
2) Label:
Used to provide a description or label for an input field.
3) Input name="FirstName"
Used to identify data when it is sent to the server.
4) Step:0.01 
Specifies the increment or decrement value, for example, 0.01.
5) Type="Submit":
Used to submit the data.
6) Thead:
Represents the header section of a table and contains column headings.
7) Tbody:
Represents the body section of a table and contains the data.
8) Ul:
Used to create an unordered list.
9) Li:
Used to create an item inside a list.
10) Border:
Used to define the table borders.
11) Div:
Used to group and organize elements and make them easier to style with CSS and JavaScript.
12) Select:
Used to create a selection list (dropdown list).
13) Option:
Used to add an option inside a dropdown list.
14) Required:
Used to make entering a value mandatory
 
Note: These elements make data handling and organization easier, and simplify working with
JavaScript
